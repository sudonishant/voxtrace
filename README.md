# VOXTRACE — AI Trust Infrastructure for Voice & Digital Evidence

> Detect AI-generated / cloned voice, explain the risk with a single Trust Score, and preserve tamper-proof evidence.  
> **Detect. Explain. Verify. Preserve.**

---

## 🚀 Features

- **Voice Authenticity & Deepfake Detection:** Real-time audio stream & file analysis to detect cloned or synthesized speech.
- **Trust Score Engine:** Clear, explainable metrics providing instant risk assessment.
- **Tamper-Proof Evidence:** Cryptographic verification and tamper-evident logging for digital forensics.
- **Modern Clean UI:** Responsive, intuitive user experience designed for seamless inspection.

---

## 🛠️ Quick Start

### Run Locally

Start the static preview server:

```bash
python3 server.py
```

Then open your browser at:
- **Local:** [http://localhost:3000](http://localhost:3000)
- **Network:** `http://<your-ip>:3000`
